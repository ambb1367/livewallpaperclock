# والپیپر زنده «ساعت زنده» (ساعت شمسی)

## ساخت APK با GitHub (بدون نصب Android Studio)
1. در github.com یک حساب بسازید و یک Repository جدید (مثلاً clock) بسازید.
2. محتوای همین پوشه (همه فایل‌ها، از جمله پوشهٔ مخفی `.github`) را داخل Repository آپلود کنید
   (Add file ← Upload files؛ پوشه‌ها را بکشید و رها کنید).
   اگر پوشهٔ `.github` آپلود نشد: Add file ← Create new file، در نام فایل بنویسید
   `.github/workflows/build.yml` و محتوای همان فایل را کپی کنید.
3. به تب Actions بروید؛ ساخت خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه).
4. روی آخرین اجرا (تیک سبز) کلیک کنید؛ پایین صفحه در بخش Artifacts فایل
   PersianClockWallpaper-apk را دانلود کنید و از zip خارج کنید تا app-debug.apk به دست بیاید.
5. فایل را به گوشی بدهید و نصب کنید (اجازهٔ «نصب از منابع ناشناس» لازم است).
6. برنامهٔ «ساعت زنده» را باز کنید، سبک و رنگ را انتخاب کنید و «تنظیم به‌عنوان والپیپر» را بزنید.

## ساخت با Android Studio
پوشه را باز کنید ← Build ← Build APK(s).
